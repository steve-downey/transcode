Detailed Description

Remarks
A type models flushable_decode_codec if it can owe output after the last byte. c.flush() is called once, when the input is exhausted, and returns what the codec still owes – a truncation error for a sequence that ended mid-way, say – or nullopt if it owes nothing. A codec that does not model this concept is asked for nothing at the end of the input.
