beman.transcode

beman.transcode is a header-only C++23 library for Unicode transcoding with ranges and views. It implements the WHATWG Encoding Standard at compile time, and wraps the POSIX iconv API as a range adaptor for the encodings a platform provides. It is the reference implementation for WG21 paper P4246, "Transcoding Text Views", and part of the Beman Project.
