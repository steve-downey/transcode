# beman.transcode {#mainpage}

`beman.transcode` is a header-only C++23 library for Unicode transcoding with
ranges and views.  It is the reference implementation for WG21 paper P4246,
"Transcoding Text Views".

The paper, D4246R1, is available as
[HTML](paper/transcode-view.html) and [PDF](paper/transcode-view.pdf).
