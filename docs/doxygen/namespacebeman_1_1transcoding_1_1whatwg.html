enum class beman::transcoding::whatwg::error
strong
Remarks
An operation that fails to decode or to encode reports one of these values. The enumerators have the meanings in the following table. \libtab2[transcode.errors.whatwg]{Enum class whatwg::error} \column Constant \column Meaning \row invalid_byte \cell the input holds a byte the encoding does not allow in that position. \row truncated_sequence \cell the input ends in the middle of a sequence. \row overlong_encoding \cell the sequence encodes a value that a shorter sequence also encodes. \row surrogate_code_point \cell a byte sequence decodes to, or a UTF-32 input code unit holds, a surrogate code point, which is not a Unicode scalar value. \row out_of_range \cell a byte sequence decodes to, or a UTF-32 input code unit holds, a value greater than the largest Unicode scalar value. \row unmapped_codepoint \cell the encoding has no representation for the Unicode scalar value being encoded. \endlibtab2

Returns
The encoding r begins with a byte order mark for: \item whatwg::encoding::utf_8, if r begins with EF BB BF; \item whatwg::encoding::utf_16be, if r begins with FE FF; \item whatwg::encoding::utf_16le, if r begins with FF FE; \item nullopt otherwise.

◆ get_encoding()

std::optional< encoding > beman::transcoding::whatwg::get_encoding ( std::string_view label)
constexprnoexcept
Returns
The encoding whose WHATWG label set contains label, and nullopt if no encoding has that label. Leading and trailing ASCII whitespace is ignored and the comparison is ASCII case-insensitive, which is the Encoding Standard's "get an encoding" algorithm.
Remarks
An encoding's labels are the alternative names a document may spell it with – latin1, iso-8859-1 and windows-1252 are all labels of whatwg::encoding::windows_1252 – so a lookup that fails is a name no encoding claims, not an encoding that cannot be represented.

◆ transcode_string() [2/2]

std::optional< std::string > beman::transcoding::whatwg::transcode_string ( std::span< const char > src,
whatwg::encoding from,
whatwg::encoding to )
inline
Returns
nullopt if the WHATWG Encoding Standard defines no encoder for to; otherwise, the bytes of src, decoded as from and re-encoded as to. Errors are substituted rather than reported: a byte sequence from does not allow decodes to U+FFFD, and a scalar value to cannot represent encodes to '?'.
Remarks
This is transcode \iref{transcode.pipeline} run to completion into a string, which is what a caller who wants the whole result and not a view writes. src | whatwg::transcode<From, To> | ranges::to<string>() is the same thing with the codecs known at compile time.

auto beman::transcoding::whatwg::decode = transcoding::decode(whatwg::decoder<C>{})
inlineconstexpr

\seebelow

Remarks
whatwg::decode<C> is decode(whatwg::decoder<C>{}) \iref{transcode.codec.decode}. It is the codec-object adaptor over the library's decoder for the encoding C, the decoder as the Encoding Standard defines it. The value type, the reporting of decoding errors, the laziness and the range properties of the view it adapts to are those of that adaptor. An argument of array type is ill-formed: a string literal carries a terminating null character that a decode would render, and views::null_term \iref{null.term.adaptor} is how a null-terminated sequence becomes a range.

whatwg::encode<C> is encode(whatwg::encoder<C>{}) \iref{transcode.codec.encode}. It is the codec-object adaptor over the library's encoder for the encoding C, the encoder as the Encoding Standard defines it. The value type, the reporting of encoding errors, the laziness and the range properties of the view it adapts to are those of that adaptor; the view is random access for the single-byte encodings, which single_byte_text_encoder \iref{transcode.codec.reqs} provides. ◆ transcode

template<encoding From, encoding To>
auto beman::transcoding::whatwg::transcode = detail::make_whatwg_transcode_adaptor<From, To>()
inlineconstexpr

\seebelow

Remarks
whatwg::transcode<From, To> is transcode(whatwg::decoder<From>{}, whatwg::encoder<To>{}) \iref{transcode.pipeline}, and so is E | whatwg::decode<From> | whatwg::encode<To> for a subexpression E that models legacy_byte_range. An E of array type is ill-formed.

The composition is the specification: the pipeline decodes and re-encodes one element at a time, and it is lazy because its parts are. A scalar value To cannot represent is an encoding error, reported as whatwg::encode reports one; a byte sequence From does not allow is a decoding error, and the U+FFFD it decodes to is what gets encoded.

Mandates: The Encoding Standard defines an encoder for To.
