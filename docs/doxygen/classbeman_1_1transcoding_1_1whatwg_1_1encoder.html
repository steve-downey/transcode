Detailed Description

template<encoding C>
requires detail::whatwg_encode_codec<C>
class beman::transcoding::whatwg::encoder< C >

\at transcode.whatwg.encoders

Remarks
whatwg::encoder<C> is the encoder, as a codec object, for the encoding C. $whatwg-encode-codec$<C> is true for every encoding but utf_16be, utf_16le, replacement and x_user_defined, for which the Encoding Standard defines no encoder, and $random-access-encode-codec$<C> is true when C is one of the Encoding Standard's single-byte encodings other than x_user_defined. It models text_encoder \iref{transcode.codec.reqs} and the encode adaptor over it \iref{transcode.codec.encode} yields what whatwg::encode<C> does. It models flushable_text_encoder when C is encoding::iso_2022_jp, which owes an escape sequence returning to ASCII after the last scalar value. It models single_byte_text_encoder when C names a single-byte encoding. It is equality comparable.
