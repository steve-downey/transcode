Detailed Description

\at transcode.whatwg.dynamic

Remarks
whatwg::dynamic_decoder is a decoder, as a codec object, for an encoding chosen at run time. Each operation behaves as the same operation of whatwg::decoder<E> does, where E is the encoding it was constructed with. It models text_decoder, flushable_text_decoder and bom_aware_text_decoder \iref{transcode.codec.reqs} whatever the encoding, so the decode adaptor over it \iref{transcode.codec.decode} yields what whatwg::decode<E> does. It does not model single_byte_text_decoder. It is equality comparable; two objects are equal if they decode the same encoding and are in the same state.
