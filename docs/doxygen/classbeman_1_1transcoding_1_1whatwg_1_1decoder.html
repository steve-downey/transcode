Detailed Description

template<encoding C>
class beman::transcoding::whatwg::decoder< C >

\at transcode.whatwg.decoders

Remarks
whatwg::decoder<C> is the decoder, as a codec object, for the encoding C the Encoding Standard defines. It models text_decoder \iref{transcode.codec.reqs} for every encoding, and the decode adaptor over it \iref{transcode.codec.decode} yields what whatwg::decode<C> does. It models single_byte_text_decoder when C names an encoding that decodes one byte to one scalar value, flushable_text_decoder when C names an encoding whose decoding can leave a result owed after the last byte, and bom_aware_text_decoder when C names a UTF encoding: its decode_first discards one leading U+FEFF BYTE ORDER MARK from the text it decodes. $strips-leading-bom$<C> is true when C is utf_8, utf_16be or utf_16le, $has-decode-state$<C> is true when C is utf_16be, utf_16le, gbk, gb18030, big5 or iso_2022_jp, and $random-access-decode-codec$<C> is true when C is x_user_defined or one of the Encoding Standard's single-byte encodings. It is equality comparable.
